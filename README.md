# meetings_workflow

LlamaIndex 기반 Agent 구현

(1) 회의록 시스템 어시스턴트 기능: 
- 회의 내용 질의 응답 자연어 검색: "지난주 마케팅 회의에서 예산 관련해서 뭐라고 했지?" 같은 질문에 회의록을 근거로 답변 
- 다중 회의 통합 검색: 여러 회의록을 넘나들며 특정 주제나 키워드의 흐름 추적 (예: "A 프로젝트가 지난 3번의 회의에서 어떻게 논의됐는지 요약해줘")
- 화자별 발언 요약: "김 팀장이 이번 분기에 언급한 이슈들 정리해줘"
- 액션 아이템 관리 회의록에서 할 일(Task), 담당자, 기한을 자동 추출 "내가 이번 주에 처리해야 할 액션 아이템 뭐 있어?" 같은 질문에 답변
- 후속 회의 준비 지원 "다음 회의 전에 지난 회의 안건 중 아직 안 끝난 거 알려줘" 이전 회의 대비 안건의 변화나 진행 상황 비교
  
(2) 기존 회의록 데이터는 JSON 형태로 저장되어 있음.
JSON의 key에는 "일시", "참석자", "회의 안건", "Action Item"이 있음.
[예시]
  {
    "회의 ID": "mkt-2026-07-24",
    "일시": "2026-07-24T10:00:00",
    "참석자": "김민준 팀장, 박서연, 이도현",
    "회의 안건": ["A 프로젝트 킥오프", "3분기 마케팅 예산 배분"],
    "회의 내용": "김민준 팀장이 A 프로젝트 킥오프를 선언했다. 3분기 마케팅 예산은 총 5천만원으로 확정되었고, 이 중 3천만원을 A 프로젝트 온라인 광고에 배정하기로 했다. 박서연은 광고 채널을 SNS 중심으로 구성하겠다고 제안했다. 이도현은 경쟁사 대비 예산이 다소 부족할 수 있다는 우려를 제기했다.",
    "결정사항": ["3분기 마케팅 예산 5천만원 확정", "A 프로젝트에 3천만원 배정"],
    "Action Item": [
      {"할 일": "SNS 광고 채널 후보 리스트업", "담당자": "박서연", "기한": "2026-07-31", "상태": "완료"},
      {"할 일": "경쟁사 예산 벤치마킹 자료 준비", "담당자": "이도현", "기한": "2026-08-05", "상태": "완료"}
    ]
  }

(3) Agent workflow 
사용자 질의 -> Agent 의도 파악
-> (회의록 시스템 어시스턴트 기능과 무관한 경우) 답변 거부 및 종료
-> (기존 대화 맥락 유지 필요한 경우) 사용자 질의로 진행
-> (회의록 시스템 어시스턴트 기능에 부합하는 경우) 사용자 질의 내 정보 추출하여 json의 key 요소들에 매핑
                     -> (필수 요소가 포함되어 있는지 확인) -> 누락 시 사용자에게 요청
                                                                                                     -> (필수 요소가 포함되어 있는 경우) -> RAG 수행하여 답변
(4) 워크플로우
StartEvent (chat_history)
  │
  ▼
[1] classify_relevance  ── 무관 ──▶ StopEvent("죄송해요, 회의록 관련 질문만 도와드릴 수 있어요")
  │
  │ 맥락 유지 필요 / 신규 질의 (둘 다 진행, 맥락 유지는 chat_history 전체를 참조)
  ▼
[2] extract_slots_and_task_type
      - slots: 일시 / 참석자 / 회의 안건 / Action Item 중 매핑되는 값
      - task_type: QA | SUMMARY | ACTION_ITEM_LOOKUP | FOLLOWUP_COMPARE | STATS | EDIT
  │
  │ 필수 슬롯 누락 ──▶ StopEvent("어떤 회의를 찾아드릴까요? 일시나 참석자를 알려주세요")
  ▼
[3] route_by_task_type
  ├─ QA / SUMMARY / STATS / FOLLOWUP_COMPARE ──▶ [4a] RAG 검색 ──▶ [5] 답변 생성 ──▶ StopEvent
  ├─ ACTION_ITEM_LOOKUP ──▶ [4b] 구조화 인덱스 필터(담당자/기한) ──▶ StopEvent
  └─ EDIT ──▶ [4c] 대상 문서/필드 특정 ──▶ [4d] 수정안 제시 ──▶ (확인 대기) ──▶ [4e] 저장 ──▶ StopEvent
